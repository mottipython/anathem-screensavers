# Anathem screensavers

Screensavers from Neal Stephenson's novel *Anathem*, for Linux, Windows and macOS.
Each is its own small program with its own installers: an `.rpm` for Fedora and
Nobara, a `.deb` for Debian, Ubuntu and Mint, a Windows setup program that adds it
to Screen Saver Settings, and for the Mac a screen saver module and an app.

They are unofficial fan projects. *Anathem* and everything in it are Neal
Stephenson's. The pictures were drawn with Google Gemini; the maths, the motion and
the timekeeping are computed.

## Running them on Linux

Wayland desktops have no screensaver service, so each of these can start itself
when the session is idle. If you install more than one, or want a list to choose
from, there is a companion:

**[screensaver-service](https://github.com/mottipython/screensaver-service)** is a small idle service with a
classic chooser: a picture of a monitor, a list, Preview, and how long to wait. It
adds a page to KDE System Settings, runs the old xscreensaver collection as well,
and never locks the screen. On Fedora and Nobara:

    sudo dnf copr enable mottipython/screensaver-service
    sudo dnf install screensaver-service screensaver-service-kcm

## What is tested

The first thirteen have been tested on a Mac, on Windows and on Fedora-based Linux.
Hemn Space is new: it has been run on Nobara 44, and its other builds have only
been through the automated tests.

- **macOS:** macOS 15 on Intel. Each one installs, shows up in Screen Saver
  settings, previews and runs. They are built for macOS 11 and later, Apple Silicon
  and Intel; Apple Silicon has not been tried by a person yet.
- **Windows:** Windows 11. The setup program installs each one into Screen Saver
  Settings.
- **Fedora and Nobara:** the `.rpm` packages are in daily use on Nobara 44 (Fedora
  44) with KDE Plasma on Wayland.
- **Debian, Ubuntu and Mint:** every `.deb` is installed and run on Ubuntu 24.04,
  Ubuntu 25.04, Debian 13 and Mint 22 by an automated test
  ([the last run](../../actions/workflows/test-debs.yml)). That shows each one
  installs and draws; nobody has yet watched one on a Debian desktop.

Reports are welcome.

## On a Mac

Paste this into Terminal to install all of them as screen savers, for your user,
with no password needed:

    curl -fsSL https://raw.githubusercontent.com/mottipython/anathem-screensavers/main/tools/mac-install.sh | sh

It opens the Screen Saver settings when it has finished; they are at the end of the
list. To install only some, name them:

    curl -fsSL https://raw.githubusercontent.com/mottipython/anathem-screensavers/main/tools/mac-install.sh | sh -s -- edhar-clock wick teglon

And to take them off again:

    curl -fsSL https://raw.githubusercontent.com/mottipython/anathem-screensavers/main/tools/mac-install.sh | sh -s -- --uninstall

The names are `teglon`, `lazy-peregrin`, `cutting-the-cake`, `edhar-clock`,
`weed-war`, `daban-urnud`, `adrakhonic`, `analemma`, `bolt-chord-sphere`, `wick`,
`fraa-in-orbit`, `fly-bat-worm`, `page-trees` and `hemn-space`.

Every release also has the two Mac files to download by hand, for Apple Silicon and
Intel, macOS 11 or later: the screen saver module (`-mac-screensaver.zip`; unzip and
double-click the `.saver` file) and an ordinary full-screen app (`-mac.zip`). They
are not signed with an Apple developer certificate, so when downloaded in a browser
macOS refuses them at first: allow them under System Settings, Privacy & Security.
The command above avoids that.

Tried on macOS 15 on Intel, in a virtual machine: all thirteen install, show their
preview in System Settings and run as the screen saver. Not yet tried on Apple
Silicon or with a real graphics card; reports are welcome. `tools/mac-test.sh` tries
every one in turn and writes a report.
