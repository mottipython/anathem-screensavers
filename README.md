# Anathem screensavers

Screensavers from Neal Stephenson's novel *Anathem*, for Linux, Windows and macOS.
Each is its own small program with its own installers: an `.rpm` for Fedora and
Nobara, a `.deb` for Debian, Ubuntu and Mint, a Windows setup program that adds it
to Screen Saver Settings, and for the Mac a screen saver module and an app (both
experimental).

They are unofficial fan projects. *Anathem* and everything in it are Neal
Stephenson's. The pictures were drawn with Google Gemini; the maths, the motion and
the timekeeping are computed.

## Running them on Linux

Wayland desktops have no screensaver service, so each of these can start itself
when the session is idle. If you install more than one, or want a list to choose
from, there is a companion:

**[screensaver-service](https://github.com/mottipython/screensaver-service)** is a small idle service with a
classic chooser: a picture of a monitor, a list, Preview, and how long to wait. It
adds a page to KDE System Settings, runs the old xscreensaver collection as well,
and never locks the screen. On Fedora and Nobara:

    sudo dnf copr enable mottipython/screensaver-service
    sudo dnf install screensaver-service screensaver-service-kcm

## What is tested

- **Fedora and Nobara:** the `.rpm` packages are the ones in daily use on Nobara 44
  with KDE Plasma on Wayland.
- **Debian, Ubuntu and Mint:** every `.deb` is installed and run on Ubuntu 24.04,
  Ubuntu 25.04, Debian 13 and Mint 22 by an automated test
  ([the last run](../../actions/workflows/test-debs.yml)). That shows each one
  installs and draws; nobody has yet watched one on a Debian desktop.
- **Windows:** the installers for Teglon and the Lazy Peregrin have been tried on
  Windows 11. The others are built the same way but untried.
- **macOS:** see below.

Reports are welcome.

## On a Mac

Every release has two Mac downloads, for Apple Silicon and Intel, macOS 11 or later:

- **The screen saver** is the file ending `-mac-screensaver.zip`. Unzip it,
  double-click the `.saver` file and let macOS install it, then choose it in System
  Settings, Screen Saver, at the end of the list.
- **The app** is the file ending `-mac.zip`: the same thing as an ordinary program
  that runs full screen until a key is pressed.

Neither is signed with an Apple developer certificate, so macOS refuses them at
first: allow them under System Settings, Privacy & Security.

To fetch and try all of them at once, paste this into Terminal. It installs every
screen saver module for your user, shows each app in a window for a few seconds,
and writes a report:

    curl -fsSL https://raw.githubusercontent.com/mottipython/anathem-screensavers/main/tools/mac-test.sh | sh

The Mac builds are experimental. On macOS 15 on Intel (in a virtual machine) all
thirteen apps open and draw, and all thirteen modules install. They have not yet
been tried on Apple Silicon or on a Mac with a real graphics card. If you try one,
please say how it went.
